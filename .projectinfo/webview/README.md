# Webview Documentation

## HTML Templates

### main.html

Base template that includes:

- Sidebar navigation
- Content container
- Modal system

### soql-panel.html

SOQL query editor interface with:

- Query input
- Results table
- Export options

### meta-explorer.html

Metadata browser interface with:

- Object list
- Field details
- Relationship navigation

### settings.html

Settings panel for:

- Theme selection
- Session management

## Styles

style.css provides theming and layout for all components
